# Personal Portfolio Website

A modern, responsive personal portfolio website built with **Next.js, React, TypeScript, and Tailwind CSS** to showcase my technical skills, software development projects, academic background, certifications, and extracurricular activities.

---

## 📌 Overview

This portfolio serves as a central platform to present my journey as an IT undergraduate at the University of Moratuwa and highlight my interests and experience in software engineering.

The website is designed with a focus on modern UI/UX, responsive layouts, reusable components, and maintainable code. It provides visitors with an overview of my technical capabilities, academic achievements, and software development projects.

## ✨ Features

- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- **Modern UI/UX** — A clean interface with a modern purple, violet, and pink visual theme.
- **Interactive Animations** — Smooth transitions and engaging interface elements.
- **Projects Showcase** — Dedicated sections for presenting projects, technologies, features, and contributions.
- **Technical Skills** — Organized presentation of programming languages, frameworks, tools, and technologies.
- **Education** — Academic background and achievements.
- **Certifications** — Professional learning achievements and completed courses.
- **Extracurricular Activities** — Leadership, teamwork, and university involvement.
- **Contact Section** — Provides ways to connect with me professionally.
- **Reusable Components** — Modular UI components for maintainability and consistency.
- **Structured Data** — Portfolio information organized into separate data modules.

## 🧩 Customization

Portfolio content is organized into data modules to make updates easier.

You can customize:

- Personal information and profile details
- Technical skills and technologies
- Project descriptions, features, and repository links
- Education and academic achievements
- Certifications and completed courses
- Extracurricular activities and leadership experience
- Contact information and social links

Keeping content separate from UI components helps improve maintainability and makes the portfolio easier to extend.
